Flutter 구현 시 주의사항
ReorderableListView (D4=A): 각 waypoint 항목에 고유 Key 필수. START/GOAL 항목도 드래그 허용하되 재배열 후 role 재계산 (첫 번째 = START, 마지막 = GOAL, 나머지 = VIA).

저장 버튼 활성 조건 (D5=B + D7=A): previewSuccess && !waypointsChangedSincePreview. "경로 미리보기" 버튼 클릭 시 POST /courses/preview 1회 호출 → 성공 시 05_preview로 이동. 05에서 "저장" 버튼 활성. 05에서 "다시 편집" 클릭 시 02로 돌아오면 waypointsChangedSincePreview = true로 세팅 → 저장 버튼 비활성 + stale 안내 배너 표시 ("경유지를 변경했습니다. 미리보기를 다시 실행하세요"). debounce 정책 없음.

장소 선택 시트 (D3=A): showModalBottomSheet + SafeArea 필수. place 리스트는 기존 allPlacesProvider 재사용. 거리는 현재 지도 카메라 중심 기준 계산.

크로스헤어 (04 지도 편집): 지도 위 Stack에 절대 배치. 지도 카메라 이동 → onCameraIdle 콜백에서 중심 좌표 캡처. 카메라 이동 중 좌표 라벨은 이전 값 유지(렉 방지).

SafeArea (shell 밖 전체 화면): 하단 고정 버튼 영역 SafeArea(top: false) 필수. 지도 영역 배경 그래디언트 없어서 body 전체 SafeArea도 허용.

복사 편집 (D6=A + D5=B): 라우트 /riding-courses/:id/copy. CourseEditScreen에 sourceCourse 파라미터 옵셔널로 넘기면 name/waypoints 프리필 + sourceCourseId 세팅. 프리필 직후에도 자동 Directions 호출 없음. 사용자가 "경로 미리보기" 버튼을 직접 눌러야 폴리라인 생성.

flutter-dev에게 전달할 미결 사항

⚠️
경유지 15개 도달 시 "+ 경유지 추가" 버튼 완전 숨김 vs 비활성 처리 — 목업에서는 비활성 패턴으로 표현됨. flutter-dev 판단 위임.
⚠️
waypoint 개수 2개 미만(START만 있거나 GOAL 없음)에서 미리보기 버튼 활성 여부 — Naver Directions는 최소 출발+도착 2개 필요. 1개일 때 안내 토스트 권장.
⚠️
미리보기 버튼 로딩 상태 — loadingCountProvider 제외 대상(background 요청). "경로 미리보기" 버튼 내부 스피너로 표시 (CupertinoActivityIndicator). 실패 시 토스트 + 버튼 재활성, 저장 비활성 유지.
⚠️
편집 중 오프라인 진입 시 UX — 미리보기/저장 버튼 비활성 + "온라인이 필요합니다" 배너. 목업 04(지도 편집)에는 표현 안 됨.
ℹ️
기존 코스 편집(PATCH): regeneratePath: true 플래그. waypoints 변경 시 앱이 자동으로 true 세팅. 이름/공개여부만 바꾸면 false.
ℹ️
place 선택 시 place_id + 좌표/이름 스냅샷 둘 다 저장 (1차 DB 설계와 동일). place 삭제 후 편집 시 해당 waypoint는 place_id=null, 임의 지점으로 표시.

flutter-dev 주의사항

SafeArea: 이 화면들은 shell 밖 전체 화면. 하단 액션바 + 홈 인디케이터 대응 필수.
하단 고정 버튼: SafeArea(top: false) 또는 EdgeInsets.only(bottom: MediaQuery.of(context).viewPadding.bottom)

지도 롱프레스 구현: NaverMapController.onMapLongTapped 콜백으로 좌표 수신 → WaypointEntity 생성 → 로컬 리스트에 VIA로 추가.

ReorderableListView 주의: START·END는 reorder 불가 처리 (key는 필수, START·END 항목은 드래그 핸들 비활성화).
실제 구현 시 onReorder 콜백에서 START(index 0)·END(마지막 index) 이동을 무시(guard).

Directions API 호출 시점: "미리보기" 버튼 클릭 시 1회만 호출. waypoint 좌표 변경 없이 다시 누르면 캐시 응답 재사용 권장.

저장 차단(D7): AppBar "저장" 버튼은 _previewCompleted 상태 변수로 enable/disable 제어. Directions 실패 시 snackbar 표시 후 저장 불가.

결정 필요 사항 (flutter-dev 착수 전 확인)

place-selection-sheet에서 "임의 지점 추가" 버튼 필요 여부
목업에서는 시트에서 등록 장소만 선택하고, 임의 지점은 지도 롱프레스로만 추가합니다. 시트 안에 "지도에서 직접 찍기" 버튼을 추가할지는 flutter-dev 판단 위임.

하단 시트 높이 동적 조절
검색 결과 개수에 따라 시트 높이를 DraggableScrollableSheet로 조절할지, 고정 높이(최대 60% 화면)로 스크롤할지 flutter-dev 판단 위임.
